Switch buttons

Dark — 仕事 active

Light — 休息 active

常にちょうど1つがアクティブです。「未選択」状態はありません。押されたボタンはその活動の保存された色で塗られ、 ラベルが #fff に、ボーダーが同色になります。それだけ — グロー（色付きの drop shadow）は付けません。 アクセント色で着色した影は「AI っぽさ」の最大の原因で、塗りだけで状態は十分伝わります。色は要素の --activity として渡し、残りはスタイルシートが処理します。
flex-wrap で折り返します — Web に出す面で display:grid は使えません（react-native-web が落とします）。 macOS menubar の 3×2 グリッドはネイティブ専用なので例外です。
